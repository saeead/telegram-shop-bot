# Agent Evaluator Rubric

Score 0–2 for each dimension:

1. **Correctness** — behavior matches feature acceptance criteria.
2. **Verification** — required tests/checks were actually executed and evidence is recorded.
3. **Scope discipline** — work stayed within the selected feature and documented dependencies.
4. **Reliability** — restart/retry/replay behavior is safe where applicable.
5. **Maintainability** — boundaries, names, tests, and docs are clear to a fresh agent.
6. **Handoff readiness** — another agent can continue using repository artifacts only.

Decision: Accept / Revise / Block.

Do not let the agent be its own final judge without human spot checks. Tune this rubric against actual review outcomes over several iterations.
