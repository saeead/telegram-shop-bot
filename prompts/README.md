# Six-Phase Agent Prompts

These prompts are intentionally placeholders until the Phase 1 harness is verified. Each phase prompt will:
1. read repository state;
2. select exactly one feature at a time;
3. implement only the required slice;
4. test it;
5. record evidence;
6. update progress/handoff;
7. stop in a clean state.

The six prompts will be finalized after the foundation is runnable, because later prompts must refer to actual commands, paths, migrations, and verified interfaces rather than assumptions.
