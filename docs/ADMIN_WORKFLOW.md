# Admin Workflow

1. Receive forwarded batch.
2. Show classification summary.
3. Ask name.
4. Ask category.
5. Ask price/currency.
6. Ask future optional metadata as configured.
7. Render review card.
8. Confirm or cancel.
9. Publish to Store/Archive/Backup.
10. Record audit event and evidence.

Later administration includes edit price, edit category/tags, hide/delete, republish, inspect order/payment/delivery status.
